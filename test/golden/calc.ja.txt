定理（chain）.
  任意の自然数 a、b、c、d に対して a = b、b = c、および c = d ならば a = d。

証明.
a、b、c、d を自然数とする。a = b（これを h1 とおく）、b = c（これを h2 とお
く）、および c = d（これを h3 とおく）と仮定する。示すべきことは a = d であ
る。次のように計算する:
  a = b    （h1 による）
    = c    （h2 による）
    = d    （h3 による）

∎

定理（append_nil'）.
  任意のリスト l に対して l ++ [] = l。

証明.
l をリストとする。示すべきことは l ++ [] = l である。リスト l に関する帰納法
で示す。

基底の場合（nil）.
  示すべきことは [] ++ [] = [] である。これは両辺が同一であることにより成り
  立つ。

帰納段階（cons）.
  x を自然数、および xs をリストとする。帰納法の仮定 ih により xs ++ [] =
  xs が使える。示すべきことは x :: xs ++ [] = x :: xs である。
  List.cons_append、および ih により書き換えると、証明が終わる。

∎
