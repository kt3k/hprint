定理（exists_gt）.
  任意の自然数 n に対して n < m を満たす 自然数 m が存在する。

証明.
n を自然数とする。示すべきことは n < m を満たす 自然数 m が存在することであ
る。n + 1 を取ればよい。残るは n < n + 1 を示すことである。これは線形算術に
より成り立つ。

∎

定理（double_of_even）.
  任意の自然数 n に対して n = 2 * k を満たす 自然数 k が存在する ならば n +
  n = 2 * m を満たす 自然数 m が存在する。

証明.
n を自然数とする。n = 2 * k を満たす 自然数 k が存在する（これを h とおく）
と仮定する。示すべきことは n + n = 2 * m を満たす 自然数 m が存在することで
ある。h から n = 2 * k を満たす k が得られる。n を取ればよい。残るは n + n
= 2 * n を示すことである。これは線形算術により成り立つ。

∎

定理（le_of_have）.
  任意の自然数 a、b に対して a = b ならば b = a。

証明.
a、b を自然数とする。a = b（これを hab とおく）と仮定する。示すべきことは b
= a である。hab により a = b（これを h とおく） が成り立つ。これはh.symmによ
り成り立つ。

∎
